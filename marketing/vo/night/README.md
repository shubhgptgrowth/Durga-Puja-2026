# Voiceover for the night-map route reels

English first (the owner's call for route and pandal posts, 17 Oct). One folder per area, one file per line: `marketing/vo/night/<zone>/1.m4a` … `5.m4a` (mp3, wav, ogg/opus voice notes and aac work too).
When a folder is there, the reels factory trims the silence off each line, evens out the loudness, stretches each beat of the reel to fit its line and drops the dhak under the voice. Without it, the reel runs on the dhak alone.

Regenerate with `python -m marketing.night_route --zone <zone> --area "<Area>" --next-zone <next> --script`.
