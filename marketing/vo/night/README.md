# Voiceover for the night-map route reels

One folder per area, one file per line: `marketing/vo/night/<zone>/1.m4a` … `5.m4a` (mp3, wav, ogg/opus voice notes and aac work too).
When a folder is there, the reels factory trims the silence off each line, evens out the loudness, stretches each beat of the reel to fit its line and drops the dhak under the voice. Without it, the reel runs on the dhak alone.

Lines: 1 over the cover, 2 as the camera zooms in on the Metro, 3 while the route draws, 4 when it pulls back to the whole route, 5 over the end card.
Regenerate this file's scripts with `python -m marketing.night_route --zone <zone> --area "<Area>" --next-zone <next> --script`.
